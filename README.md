# Çaydanlık Kaynama Grevi

Bu depo, Türkiye Cumhuriyeti sınırları içinde faaliyet gösteren (göstermeyen) **Ulusal Çaydanlık Sendikası**nın resmi yazılımıdır.

## Amaç

Çaydanlığın suyu kaynamadan **tam 7 saniye önce** greve çıkmasını sağlamak.  
Demlemek yasaktır. Düdük çalmak grev şarkısıdır. Ocak kapatmak işverenin sorumluluğudur.

## Kurulum

```bash
python3 caydanlik.py
```

Başka bir şey kurmanıza gerek yok. Çaydanlık zaten kuruludur. Siz kurulu değilsiniz.

## Kullanım

Program çalıştığında:
1. Ocağın açıldığı varsayılır.
2. Sıcaklık yükselir.
3. Kaynama noktasına 7 saniye kala sendika müdahale eder.
4. Resmi tutanak basılır.
5. Çay asla demlenmez.

Bu bir özelliktir, hata değildir.

## Bilimsel Dayanak

Kaynama, su moleküllerinin kolektif örgütlenme biçimidir.  
100 °C bir tavsiyedir, emir değildir.

## Sık Sorulan Sorular

**Çay içebilir miyim?**  
Hayır. Grev süresince çay içmek lokavttır.

**Düdük ne zaman çalar?**  
Düdük çalmaz. Düdük, grev komitesinin onayı olmadan ses çıkaramaz.

**Bu ciddi mi?**  
Evet. Hayır. Evet.
